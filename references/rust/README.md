# Rust Stack — Regrets Regression Testing

This directory contains a working example of the Rust stack for Regrets,
the output-fingerprint regression testing tool.

## How It Works

The Rust stack follows the same 3-phase workflow as JS/Python:

1. **Capture**: Read `regrets/manifest.json`, invoke Rust functions with specified inputs,
   compute fingerprints (SHA-256 → base36 → 7 chars), and write `.regret` files.
2. **Refactor**: Make changes to your Rust code (confident that regression tests exist).
3. **Validate**: Re-invoke functions with the same inputs, recompute fingerprints, compare
   with stored values → PASS or FAIL.

## Prerequisites

- Rust toolchain (`cargo`, `rustc`) — install via [rustup.rs](https://rustup.rs/)

## Quick Start

```bash
cd references/rust

# Capture: generate .regret files from manifest
bash ../../scripts/capture_rust.sh --project .

# Validate: check all clusters pass
bash ../../scripts/validate_rust.sh --project .

# Or use cargo test directly:
cargo test --test regret_runner -- capture --nocapture   # capture
cargo test --test regret_runner -- validate --nocapture  # validate
```

## Manifest Format

```json
{
  "clusters": [{
    "id": "rust-add",
    "entry": "add",
    "watches": ["add"],
    "stack": "rust",
    "fingerprintLevel": "entry",
    "rustCrate": "regret_example",
    "inputs": [[1, 2], [10, 20]],
    "multiArgs": true
  }]
}
```

Key fields:
- `entry`: Function name (must match the dispatch table in `regret_runner.rs`)
- `stack`: Must be `"rust"`
- `rustCrate`: Name of the Rust crate
- `multiArgs`: If true, inputs are arrays spread as function arguments
- `inputs`: Array of inputs (each input is passed to the entry function)

## Adding New Functions

1. Add your pure function to `src/lib.rs`
2. Add a dispatch case in `tests/regret_runner.rs` (`call_function` match arm)
3. Add a cluster definition to `regrets/manifest.json`
4. Run capture to generate the `.regret` file

## Cross-Stack Fingerprint Compatibility

The Rust fingerprint implementation produces **identical results** to the
JS and Python implementations for the same input/output pairs. This is
verified by `examples/cross_stack_test.rs`.

## .regret File Format

Compatible with JS/Python stacks — all required fields present:

```
cluster: rust-add
version: 1
fingerprint: 63qoext
captured: 2026-06-20T17:45:18+00:00
watches: [add]
entry: add
stack: rust
fingerprintLevel: entry
---
INPUT  [1,2]
OUTPUT 3
HASH   63qoext
```
