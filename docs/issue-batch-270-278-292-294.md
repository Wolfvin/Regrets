## Selection method

A weighted-random picker script (`scripts/pick_nonclaim_issues.py`) loaded all 15 open non-claim issues from the Wolfvin/Regrets issue tracker (excluding PRs — GitHub's REST `/issues` endpoint returns both issues and PRs, so we filter via `iss.pull_request is not None`).

Weights:
- Base weight = `2^(age_days / 30)` — exponential decay by age (half-life 30 days), so older unfixed issues are more likely to be picked.
- `[RED TEAM]` title boost: × 1.5 (red team findings are usually real bugs).
- 0-comments boost: × 1.2 (untouched = more likely still real).
- `[Integration Gap]` title boost: × 1.3 (usually real cross-module bugs).

Random seed: deterministic per-day (`YYYYMMDD + 42`), so workers running on the same day pick the same set (reduces wasted effort), but different days get different selections.

### #278 — Class callee warning suggests nonsensical arrow-function refactor

**Decision: Updated + consolidated duplicate PRs** (bug still present on main; PR #433 is the canonical fix — PR #428 closed as superseded)

**Verification:**

Reproduced the exact scenario from the issue body — a cluster with `callees: ["Thing"]` where `Thing` is a class:

```js
class Thing { constructor(x) { this.x = x } value() { return this.x } }
function main(x) { return new Thing(x).value() }
export { main, Thing }
```

Ran `node scripts/capture.js`. The current warning output is:

```
⚠️  Callee "Thing" found but module is frozen (no mutable holder available) — could not install proxy (cluster: main)
    ...
    Options to enable callee wrapping:
      1. Refactor to a supported pattern (see list above) and ensure the callee
         name is not shadowed anywhere in the file.
      2. For CJS: call the callee via `module.exports.Thing(...)` instead
         of the bare name — this works without source transformation.
```

**Bug still present:** The warning suggests "Refactor to a supported pattern" — but the supported patterns listed (`function foo()`, `export const foo = () => {}`) don't apply to classes. A class cannot be refactored to `export const Thing = () => {}` without losing `new` semantics, prototype chain, `instanceof`, etc.

| #433 | `verify/batch-278-279-280-286` | `scripts/ghost.js` (+49/-23) + `tests/issue-278-class-callee-warning.test.js` (+197) | open | Consolidation of #428 — adds regression test |

Both PRs use the **identical** `ghost.js` diff (+49/-23) — they're true duplicates. PR #433 is strictly better (same fix + regression test). This batch PR closes #428 as superseded by #433.
