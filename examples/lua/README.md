# Regrets — Lua Stack Example (Luhn Checksum)

End-to-end demonstration of the Lua stack: a real Lua module, two clusters
(`luhn-checksum` and `luhn-valid`), capture → validate PASS → mutate → validate FAIL.

## Prerequisites

- Lua 5.3+ (tested with Lua 5.4.6)
- `sha256sum` (coreutils — already on Linux; macOS users may need `brew install coreutils`)

## Files

```
examples/lua/
├── src/luhn.lua               Pure-Lua Luhn algorithm (M.checksum, M.valid)
├── regrets/
│   ├── manifest.json          Two Lua clusters
│   ├── luhn-checksum.regret   (generated by capture)
│   └── luhn-valid.regret      (generated by capture)
└── README.md                  This file
```

## Phase 1 — Capture

```bash
cd examples/lua
lua ../../scripts/capture_lua.lua
```

Expected output (truncated):
```
📡 Capturing Lua clusters...

📡 Capturing: luhn-checksum
   File:    src/luhn.lua
   Entry:   checksum
   Watches: checksum
   ✅ Fingerprint: <7-char hash>
   📄 Saved: regrets/luhn-checksum.regret

📡 Capturing: luhn-valid
   ...
   ✅ Fingerprint: <7-char hash>
   📄 Saved: regrets/luhn-valid.regret

──────────────────────────────────────────────────
Capture complete: 2 captured, 0 failed
```

The `.regret` files use the identical format as JS/Python/PHP stacks:
```
cluster: luhn-valid
version: 1
fingerprint: <7-char base36 hash>
captured: 2026-06-20T...
watches: [valid]
entry: valid
stack: lua
fingerprintLevel: entry
file: src/luhn.lua
---
INPUT  "79927398713"
OUTPUT true
HASH   <7-char base36 hash>
```

## Phase 3 — Validate

```bash
lua ../../scripts/validate_lua.lua
```

After a **safe** refactor → both clusters PASS:
```
🔍 Validating 2 cluster(s)...

  ✅ luhn-checksum                       <hash>            PASS
  ✅ luhn-valid                          <hash>            PASS

────────────────────────────────────────────────────────
✅ All 2 tests passed. Refactor is safe.
```

After a **breaking** refactor (e.g. change `d * 2` to `d * 3` in `luhn_sum`):
```
🔍 Validating 2 cluster(s)...

  ❌ luhn-checksum                       <golden> → <live>  FAIL
  ❌ luhn-valid                          <golden> → <live>  FAIL

────────────────────────────────────────────────────────
❌ 2/2 FAILED.

Fix the CODE — do not edit .regret files.
Re-run: lua scripts/validate_lua.lua
```

## Cross-Stack Fingerprint Consistency

The Lua fingerprint is byte-identical to JS/Python/PHP for the same input/output
pair. Run `lua scripts/verify_fingerprint.lua` from the repo root to confirm
the cross-stack equivalence on 4 cases.

## Limitations

- `fingerprintLevel: "entry"` only (no callee re-validation). Lua has no
  equivalent of JS `Proxy` or Python `unittest.mock.patch` — watched
  functions cannot be transparently wrapped without source transformation.
  This is the same limitation as the PHP stack (see `references/php.md`).
- `sha256sum` external dependency (matches the bash-wrapper pattern used by
  `capture_go.sh` / `capture_rust.sh`).
- Lua's tables are ambiguous between arrays and objects; we treat
  `{1,2,3}` as an array and `{a=1}` as an object, matching the JS/PHP
  convention. Empty tables are treated as empty arrays.
