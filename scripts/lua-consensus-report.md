## Recommended canonical branch

**`feat/lua-stack` (PR #377)** — reasons:

1. **npm test integration**: adds `tests/capture-lua.test.js` (134 lines) so
   `npm test` validates Lua capture as part of the standard CI loop.
2. **Unified CLI**: modifies `scripts/regret.js` to dispatch to
   `capture_lua.lua` / `validate_lua.lua` when `stack === "lua"`, so users
   invoke `regret capture` / `regret validate` uniformly across all stacks.
3. **Detailed `.regret` format**: emits an `INPUTS` line listing every
   input→hash pair for multi-input clusters (not just the first one).
4. **Self-contained crypto**: ships `scripts/sha2.lua` — a clean-room
   FIPS 180-4 SHA-256 implementation (public domain), no Node coupling.
5. **Pure-Lua**: no bash dependency for the core capture/validate logic
   (unlike #380 which is bash-driven).

The other two branches (#380, #381) remain valuable as alternative
implementations and reference designs. They can be closed as duplicates
of #377 without losing any technical value — the consensus verification
proves they all produce identical fingerprints.

## How to reproduce

```bash
# From inside the Regrets repo
bash scripts/verify_lua_consensus.sh

# Or with explicit cleanup-keep:
bash scripts/verify_lua_consensus.sh --keep-worktrees
```

The script:
1. Builds Lua 5.4.7 from source if no system `lua` is available
2. Sets up the canonical fixture
3. Computes JS reference fingerprints via `scripts/fingerprint.js`
4. For each of the 3 branches: `git fetch` + `git worktree add`, run
   capture on the canonical fixture, then run validate on a deliberately
   broken fixture (must FAIL)
5. Compares all 4 sets of fingerprints (3 Lua + 1 JS)
6. Prints a PASS/FAIL consensus table

Exit code 0 = consensus PASS, 1 = FAIL, 2 = environment error.
