# CSS Stack — Independent Verification Fixture

This fixture provides an **independent** end-to-end verification of the
Regrets CSS stack (`scripts/capture_css.mjs` + `scripts/validate_css.mjs`)
on a **different** CSS codebase than the author's own `proofs/css_demo/`.

## Why a second fixture?

Per `CONTEXT.md`'s "Lesson Learned" section, verifiers must not trust
self-chosen fixtures alone — a single example can pass while hiding bugs
that only surface on different inputs. This fixture uses a **form controls
CSS domain** (input fields, submit buttons, helper text) instead of the
author's chosen **animation cue** domain. Together, the two fixtures
exercise:

| Pattern | css_demo | css_independent |
|---------|:--------:|:---------------:|
| Class selector | ✅ | ✅ |
| Compound class + pseudo-class (`:hover`) | ✅ | ✅ |
| Attribute selector (`[data-active="true"]`) | ✅ | ✅ |
| Element selector (`button`) | ❌ | ✅ |
| Multiple `@media` queries | ❌ | ✅ |
| CSS custom properties (`var(--…)`) | ❌ | ✅ |
| `:focus` pseudo-class | ❌ | ✅ |
| `:disabled` / `:active` pseudo-classes | ❌ | ✅ |
| `prefers-reduced-motion` media | ❌ | ✅ |

## Running the demo

```bash
bash proofs/css_independent/run-demo.sh
```

The demo runs 9 steps:
1. Capture 4 clusters
2. Validate (no change) → 4/4 PASS
3. Breaking change (.form-submit bg `var(--form-accent)` → `#cc0000`)
4. Validate → 1 FAIL (form-submit), 3 PASS
5. Restore form.css
6. Comment-only change → 4/4 PASS
7. `--cluster form-submit` filter → 1/1 PASS
8. Cross-stack parity (CSS HASH == JS `fingerprint()`)
9. `@media` declarations captured (font-size: 16px + transition: none)

## Cross-stack parity

All 4 clusters' `.regret` HASH values match the JS reference
`fingerprint()` (`scripts/fingerprint.js`) byte-for-byte:

```
form-input           CSS=54rtxog  JS=54rtxog  MATCH
form-submit          CSS=5yipnpb  JS=5yipnpb  MATCH

button-element       CSS=2z2m0ky  JS=2z2m0ky  MATCH
```

This confirms the 256-bit hash fix (commit `97689eb` in PR #453) works
correctly on different CSS — not just the author's chosen cue animation
example.

## .regret file format

All generated `.regret` files preserve the standard Regrets contract:

```
cluster: form-input
version: 1
fingerprint: 54rtxog
captured: 2026-06-21T...
entry: .form-input
stack: css
file: ../form.css
---
INPUT  {"selector":".form-input"}
OUTPUT ["background-color: var(--form-bg)", ...]
HASH   54rtxog
```

Required fields: `cluster`, `version`, `fingerprint`, `captured`, `INPUT`,
`OUTPUT`, `HASH`. All present, all standard.
